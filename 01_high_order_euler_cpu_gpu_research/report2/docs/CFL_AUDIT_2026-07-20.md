# Report 2 HLLC CFL audit

## Official policy

| Case family | WENO-2 | WENO-3 | ADER-3 |
|---|---:|---:|---:|
| Smooth advection | 0.40 | 0.40 | 0.25 |
| Discontinuous Euler problems | 0.20 | 0.20 | 0.14 |

The same method/problem CFL is used for serial, OpenMP, and CUDA. Historical
CFL probes remain separate because their purpose is to document stability and
backend-sensitivity tests rather than provide canonical report data.

## Audit outcome

- Smooth all-backend performance: aligned.
- Discontinuous all-backend performance at 50, 100, 200, and 600: aligned.
- Backend consistency: aligned in the active runner.
- High-resolution 2D field exports: aligned.
- OpenMP thread scaling: aligned.
- CUDA GPU-limit sweeps through the accepted 5000 endpoint: aligned.
- Phase profiling at 100 and 600: aligned.
- Old 2D convergence data: not aligned; all methods used CFL 0.35.
- Old 1D convergence data: ADER-3 was not aligned because all methods used CFL 0.40.
- Old 1D Sod field exports: not aligned because all methods used CFL 0.30.
- Older local smoke and 1D helper scripts contained common-CFL shortcuts; these
  have been replaced by the official per-method maps.

The active validation scripts now select CFL by method. The consolidated
Lovelace rerun completed on 20 July 2026 and refreshed the 2D convergence
table, the 1D convergence table, the 1D field exports, and the
backend-consistency table without repeating the already aligned performance
campaigns. The refreshed backend table records CFL and final time explicitly.

The accepted refreshed results are stored under
`results/hllc/cfl_aligned_validation/`. On the finest 2D interval,
the observed L1 density orders are 2.0067 (WENO-2), 2.9981 (WENO-3), and
2.9980 (ADER-3). All 27 backend-check fields are finite with positive density
and pressure. OpenMP matches serial exactly in the exported fields; CUDA is at
roundoff or near-roundoff except for the documented branch-sensitive
shock-bubble ADER-3 case, whose maximum energy difference is 2.02e-7.

Run `python scripts/audit_report2_cfl_policy.py` after extracting new results.
The post-extraction audit checked 18 active CFL maps and 411 canonical CSV rows
and returned `CFL POLICY PASS`.
