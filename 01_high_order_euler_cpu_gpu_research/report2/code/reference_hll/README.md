# HLL/Rusanov comparison baseline

This source tree preserves the earlier HLL/Rusanov route solely as a matched
baseline for the Report 2 accuracy-efficiency comparison. It is not the main
Report 2 implementation and must not be used as the source of the principal
validation, backend-consistency, or final physical conclusions.

The processed comparison data, scripts, and figures are stored under
`../../analysis/hll_vs_hllc/`. The official Report 2 source is
`../hllc_solver/`.
