# Scripts

This directory keeps a compact set of scripts for the representative Report 1 experiments, backend checks, and visualization.
Older exploratory scripts and duplicate historical experiment drivers were intentionally excluded from this curated repository version.

## Main Entry Points

- `run_report1_stageA_representatives.py`: generate representative Stage A accuracy and field outputs.
- `run_report1_stageB_checks.py`: run serial/OpenMP/CUDA consistency checks.
- `run_report1_runtime_scaling_2d_all_backends.py`: benchmark 2D runtime scaling across available backends.
- `run_report1_openmp_thread_scaling.py`: benchmark OpenMP thread scaling.
- `run_report1_weno2_backend_runtime.py`: benchmark WENO-2 backend runtime.
- `run_report1_weno2_2d_suite.py`: run representative 2D WENO-2 cases.
- `run_report1_weno2_2d_discontinuous.py`: run discontinuous 2D WENO-2 benchmark cases.
- `run_report1_weno2_cuda_checks.py`: run CUDA-focused WENO-2 checks when CUDA is available.

## Summary Builders

- `build_report1_accuracy_runtime_2d.py`: combine accuracy and runtime data for 2D comparisons.
- `build_report1_runtime_scaling_2d.py`: build compact runtime-scaling summary tables.
- `build_report1_runtime_discontinuous_2d.py`: build compact discontinuous-case runtime tables.
- `build_stageb_consistency_summary.py`: summarize backend consistency differences.

## Plotting And Comparison

- `render_stageA_2d_plots.py`: render representative 2D field plots.
- `plot_accuracy_runtime_2d.py`: plot accuracy-versus-runtime curves.
- `plot_runtime_scaling_2d.py`: plot runtime and speedup across backends.
- `plot_runtime_discontinuous_2d.py`: plot runtime for discontinuous 2D cases.
- `plot_openmp_thread_scaling.py`: plot OpenMP thread scaling.
- `plot_field_1d.py`, `plot_field_2d.py`, `plot_field_slice_2d.py`: render solution fields and slices.
- `plot_field_difference_2d.py`: visualize 2D field differences.
- `compare_csv_results.py`, `compare_fields_2d.py`, `compare_fields_2d_multi.py`: compare numerical outputs for consistency checks and method comparisons.

The project-level `results/` directory contains representative output data and figures generated by these scripts.
